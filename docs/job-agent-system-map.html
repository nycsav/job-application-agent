🛡️ Safeguards in place

  • Human gate at the irreversible step — nothing submits without your click (Lane A).
  • Enforcing PreToolUse hook — hooks/block-submit.mjs hard-blocks (exit 2) any click on a Submit/Apply control.
  • One keyed writer + shared dedup — keyedStage()/dedupeKey() stop duplicate rows across every source and writer.
  • Score gate — no submit unless a real score ≥ 5 is recorded (null/undefined hard-blocked).
  • Qualification gate — auto-skips roles needing a CS degree or hands-on IC coding (not Sav’s profile).
  • Permanent blacklist — Perplexity + BOI never scanned/scored/applied.
  • Batch limit — max 7 submissions/session, then a forced pause.
  • Acceptance checks — the manager validates every worker output before passing it on.
  • “Applied” only after a real submit — never speculative (a false record makes you skip a live role).
  • PII never in git — candidate.json, resumes, tokens are gitignored; email access is read-only.
  • Audit trail — every write carries who/when/why (Agent Trail).
